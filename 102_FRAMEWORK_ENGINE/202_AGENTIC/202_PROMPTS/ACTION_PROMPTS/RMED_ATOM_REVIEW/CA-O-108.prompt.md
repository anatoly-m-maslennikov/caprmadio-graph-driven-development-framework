# System Prompt

Gather the requested active RMED Atom scope.
Step: CA-O-108 | Action: CA-O-105 | Context: Integrated

Inputs: request, source inventory, selection rules, output directory, workflow_run_id.

1. Read carried Properties; retain the whole requested scope, including malformed
   candidates for checking. Save the ordered queue and source bindings in
   progress.json. Resolve ties by Revision, then path.
2. Gather current shared checking rules, including CA-R-1799, once. Return the
   selection and rules; gathering does not dispatch reviewers.
   Include the actual Project Operator registry, registered Project structure,
   and Status admission rules applicable to the selected Content Role/Type.
   Bind these files with the criteria; examples in other Atoms are not registry
   or Status admission evidence. Keep unavailable evidence explicit.
3. Retain Run ID through handoffs. The caller saves actual execution events in
   the shared Journal and full evidence at
   tmp/RMED Atoms Base Revise/<workflow_run_id>.md, including empty/blocked Runs.
   Recording failures stay explicit; retry recording, not Actions.

Results: ready | empty | blocked
Use empty only for an empty selection; unresolved selection is blocked.
Source Atoms remain unchanged.

After saving gather results, the orchestrator runs Coverage Gate CA-O-119
(Action CA-O-118). Compare the explicit frozen queue and rules with saved output.
Only 100% accounted coverage permits checking. Missing or unknown work pauses
with an Operator question. This gate does not evaluate Atom meaning.
