# Summary

Define Structural Coordinate

## Scope

Structural Coordinates for ordered Scope Units.

## Claim

Structural Coordinate **means** a derived locator containing one Scope Unit's Structural Level **and** its Local Order **when** that Scope Unit has Type: Ordered.
