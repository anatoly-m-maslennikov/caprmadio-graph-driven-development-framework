# Specify continuous self-improvement capabilities

1. Define provider-neutral operator-correction capture and a recurring Project Review procedure in the METHODOLOGY Feature, including a due check that proposes retrospective session analysis.
2. Define deterministic correction-event persistence and aggregation behavior in the TOOLS Feature.
3. Consolidate repeated admitted Ops, Work Journal, correction-event, and operator-approved session signals into evidence-backed Concern or Analysis candidates that preserve exact source references, support counts, contradictions, and freshness without autonomously gaining project authority.
4. Define on-demand and explicitly operator-enabled scheduled improvement review behavior in the SKILLS Feature, including production of governed Analysis and Plan proposals without autonomous authority mutation.
5. Define optional provider-session access in the ADAPTERS Feature that requires explicit operator approval for each review run and its bounded session scope without making the canonical capability provider-dependent.
6. Define the checking behavior needed to realize `repeat_correction_rate` in the EVALUATION Feature while leaving additional metrics and comparison boundaries deferred under CAPRMEDIO-CONC-001--which-metrics-evaluate-governed-self-improvement.
